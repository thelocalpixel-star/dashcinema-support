# DashCinema public support

Buildless support website for GitHub Pages. This repository contains only public
website files, not the iOS app source, signing files or credentials.

The root support page is suitable for prerelease support. It deliberately does
not claim to be the final app privacy policy or final subscription terms. Those
must be completed and approved for the actual paid App Store build before upload.

No analytics, advertisements, fonts from third-party CDNs or contact-form service.
The public contact supplied by the owner is thelocalpixel@gmail.com.
